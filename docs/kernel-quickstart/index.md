# Kernel Quickstart

This guide teaches you to write your own yapocis kernels. By the end, you'll understand:

- Interface file syntax
- Mako template structure
- Testing kernels across backends

```{toctree}
:maxdepth: 1

your-first-kernel
interface-basics
template-basics
testing-basics
```

## Prerequisites

Before writing kernels, you should:

1. Be comfortable using yapocis (see {doc}`/quickstart/index`)
2. Understand basic GPU computing concepts
3. Know C syntax (for OpenCL/CUDA/Metal kernels)

## What You'll Learn

1. {doc}`your-first-kernel` - Create a complete kernel from scratch
2. {doc}`interface-basics` - Understand the IDL syntax
3. {doc}`template-basics` - Write Mako templates for kernel code
4. {doc}`testing-basics` - Test your kernel across all backends
