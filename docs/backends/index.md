# Kernel Interface Reference

Yapocis supports multiple kernel languages/frameworks. The initial support was for OpenCL.

Support is now available for:

* [OpenCL](opencl.md) via PyOpencl
* [Apple Metal](metal.md) via PyMetallic []
* [NVidia Cuda](cuda.md) via PyCuda
* [Numpy](numba.md) via Numba

Yapocis is intended to be flexible and extensible to new kernel frameworks.
