# Convolvesep YAML Context Externalization - Summary

## Overview

Successfully externalized the template context for the `convolvesep` interface to YAML configuration. Unlike `operators` which has static context, `convolvesep` uses dynamically-generated Gaussian convolution kernels, so we externalized the **parameters** used to generate those kernels.

## Key Difference from Operators

**Operators**: Static list of operators
```yaml
operators:
  - [add, "+"]
  - [sub, "-"]
```

**Convolvesep**: Dynamic generation parameters
```yaml
gaussian_params:
  max_width: 150
  scale: 1.6
  limit: 0.001
  sigmas: null
```

The `convs` context (list of kernel name and weight arrays) is computed at runtime from these parameters, not stored in YAML.

## Files Created

### yapocis/interfaces/convolvesep.yml

Comprehensive YAML file with:

1. **Documentation** of the convs context structure
2. **Default parameters** for Gaussian weight generation:
   - `max_width`: Maximum kernel width (150)
   - `scale`: Sigma progression factor (1.6)
   - `limit`: Weight threshold for kernel truncation (0.001)
   - `sigmas`: Optional predefined sigma values (null for auto-generation)

3. **Example configurations** for common use cases:
   - Small kernels (fast processing)
   - Large kernels (high quality)
   - Custom sigma values

## Files Modified

### yapocis/lib/gaussian.py

**Added YAML context loading:**
```python
from yapocis.core.interface_context import load_interface_context
```

**Updated GaussianWeights.__init__:**
```python
def __init__(self, max_width=None, **kwargs):
    # Load defaults from YAML if not provided
    if max_width is None or not kwargs:
        yaml_context = load_interface_context("convolvesep")
        yaml_params = yaml_context.get('gaussian_params', {})

        # Use YAML defaults, but allow kwargs to override
        if max_width is None:
            max_width = yaml_params.get('max_width', 150)

        # Merge YAML params with kwargs (kwargs take precedence)
        for key in ['scale', 'limit', 'sigmas']:
            if key not in kwargs and key in yaml_params:
                kwargs[key] = yaml_params[key]

    self.gws = self.compute_gaussian_weights(max_width, **kwargs)
```

## How It Works

### Before (Hardcoded Defaults)

```python
class GaussianWeights:
    def __init__(self, max_width=150, **kwargs):
        # Uses hardcoded defaults in compute_gaussian_weights
        self.gws = self.compute_gaussian_weights(max_width, **kwargs)

    def compute_gaussian_weights(
        self,
        max_width: int = 100,  # Hardcoded
        scale: float = 1.6,     # Hardcoded
        limit: float = 0.001,   # Hardcoded
        sigmas: list[float] | None = None,
    ) -> list[Array]:
        ...
```

### After (YAML-Configured Defaults)

```python
# Use YAML defaults
gw = GaussianWeights()  # Uses convolvesep.yml defaults

# Override with custom params
gw = GaussianWeights(max_width=50, scale=2.0)  # Overrides YAML
```

## Context Structure

The convolvesep interface expects a `convs` parameter at runtime:

```python
convs = [
    ("gauss9", np.array([...])),    # 9-element Gaussian kernel
    ("gauss13", np.array([...])),   # 13-element Gaussian kernel
    ...
]
```

This is generated by:
```python
gw = GaussianWeights(**yaml_params)
weights_list = gw.gaussian_weights()
convs = [("gauss%d" % len(w), w) for w in weights_list]
```

## Template Usage

### Interface Template (convolvesep.interface)

```
interface convolvesep {
%for name,_ in convs:
    kernel ${name}(int vertical, width_of input, height_of input,
                   in float input, out_like input);
    kernel ${name}_h(width_of input, height_of input,
                     resident float input, resident float output);
    kernel ${name}_v(width_of input, height_of input,
                     resident float input, resident float output);
%endfor
};
```

### Kernel Template (convolvesep.mako)

```opencl
% for name, conv in convs:
<% margin = len(conv)//2 %>
__kernel void ${name}(int vertical, int width, int height,
                      __global float* a, __global float* ret) {
    size_t i = get_global_id(0);
    float sum = 0.0;
    if (!vertical && ...) {
        %for j in range(len(conv)):
        sum = sum + a[i+(${j-margin}*height)] * ${conv[j]};
        %endfor
    }
    ...
}
% endfor
```

## Benefits

1. **Centralized Configuration**
   - Default Gaussian parameters in one place
   - Easy to document and understand

2. **Flexibility**
   - Change default behavior without code modifications
   - Example configurations for common use cases
   - Programmatic override still available

3. **Backward Compatibility**
   - Existing code works unchanged
   - YAML provides better defaults than hardcoded values
   - Fallback to hardcoded defaults if YAML unavailable

4. **Documentation**
   - YAML file documents the context structure
   - Examples show common configurations
   - Clear explanation of how convs is generated

## Differences from Operators

| Aspect | Operators | Convolvesep |
|--------|-----------|-------------|
| Context Type | Static list | Generation parameters |
| Runtime | Fixed at compile time | Computed at runtime |
| YAML Contains | Actual operators | Parameters for generation |
| Size | Small (4 operators) | Variable (depends on params) |
| Complexity | Simple list | Complex numpy arrays |
